# Legacy: Proof Gallery v0

Witness grew out of **Proof Gallery**, an earlier project. Its source is no
longer in this tree. It is preserved in the repository history, and you can
browse it at the last v0 commit:

**<https://github.com/Muse-Nexus/proof-gallery/tree/547e99d>**

It is not built, not tested and not maintained. Please don't send pull requests
for it. Current work lives in `apps/` and `packages/` at the repository root.

## What Proof Gallery was

Proof Gallery was a private place to keep real evidence of being loved,
valued, connected and accomplished, with the original words or image, its
date, and its source. It ran mostly in the browser:

- Browser-local storage with encrypted backups.
- A browser folder source that could stage new files for review while the page
  was open.
- An optional hosted mode with owner-only row-level security.
- An experimental Mac companion with a private native vault, a Photos reader,
  and read-only MCP access for assistants.

It asked people to collect and review evidence themselves. Witness keeps the
same values (verbatim evidence, no invented meaning, never arguing with pain)
but is built for the days when someone will not open an app: capture and
saving are automatic, and evidence comes to you on a rhythm you chose.

The v0 safety rules that carried forward are now part of
[docs/SAFETY.md](../docs/SAFETY.md).
